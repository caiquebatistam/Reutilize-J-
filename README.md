# ♻️ Reuso Solidário

Landing page simples desenvolvida como parte de uma **ação extensionista universitária**, com o objetivo de promover o **consumo consciente** e incentivar a **troca ou doação de itens usados**.

## 📌 Objetivo

O projeto visa:

- Incentivar a **economia circular** por meio da reutilização de objetos.
- Criar uma ferramenta acessível para que usuários possam **enviar anúncios** de itens usados.
- Exibir os anúncios em **comércios locais**, através de telas digitais já existentes nos estabelecimentos.

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**
- **Node.js** (para simular o recebimento de dados no backend)

## 📸 Funcionalidades

- Envio de informações de contato e foto do item via formulário.
- Administração manual dos anúncios.
- Estrutura de catálogo para exibição simples e clara.

## 💡 Contexto Acadêmico

Este projeto foi desenvolvido durante uma disciplina de **Engenharia de Software**, tendo como base os **Objetivos de Desenvolvimento Sustentável (ODS)** da ONU, especialmente o **ODS 8 – Trabalho decente e crescimento econômico**.
